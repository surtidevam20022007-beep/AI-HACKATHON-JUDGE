# 🚀 Hackathon AI Judge

Hackathon AI Judge is an intelligent web application designed to help students improve their hackathon projects using AI-driven feedback and evaluation.

It provides structured analysis based on real hackathon judging criteria and delivers actionable suggestions to enhance project quality, innovation, and presentation.

---

## 🌟 Features

* 🤖 AI-based project evaluation
* 📊 Scoring system (innovation, UI/UX, scalability, etc.)
* 💡 Smart improvement suggestions
* 🚀 Next-step guidance for better project development
* 🌌 Immersive 3D interactive homepage (Three.js powered)
* 📱 Fully responsive and optimized experience

---

## 🧠 How It Works

1. User submits project details (description, tech stack, etc.)
2. The system analyzes the input using AI logic
3. Generates:

   * Scores based on hackathon criteria
   * Strengths & weaknesses
   * Suggestions for improvement
4. Helps users refine their project before presenting

---

## 🛠️ Tech Stack

* **Frontend:** React.js, HTML, CSS, JavaScript
* **3D Graphics:** Three.js (WebGL)
* **Backend:** Python (Flask) / Node.js
* **AI Integration:** OpenAI API (or similar)
